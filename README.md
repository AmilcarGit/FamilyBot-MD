# ✨ TheYui-MD: Evolución V9

**TheYui-MD** es un ecosistema avanzado para WhatsApp Multi-Device. No es solo un bot; es una herramienta de gestión, entretenimiento y automatización impulsada por **Node.js** y **Baileys**.

### 🌌 Novedades Críticas en V9:
*   **🌐 Dashboard Core V9:** Panel web ultra-profesional con estética Cyberpunk, consola en tiempo real (refresco de 2s), gestión de usuarios y control remoto.
*   **🛡️ Seguridad de Élite:** Sistema de **Tokens Únicos** automáticos por instalación y protección de identidad para el **Creador**.
*   **💰 Economía Global:** Sistema completo de minería, trabajos, apuestas y robos para fomentar la interacción en grupos.
*   **📥 Descargas sin Límites:** Bypass de bloqueos de WhatsApp mediante envío de documentos seguros (Lempi API).
*   **🤖 Inteligencia Artificial:** Integración nativa con Gemini AI y Text-to-Image (NyxDLaPI).

# 🚀 Instalación Rápida

```bash
git clone https://github.com/AmilcarGit/TheYui-MD
cd TheYui-MD
npm install
npm start
```

# 🌐 Panel de Control Web
Accede a tu centro de mando desde cualquier navegador móvil (optimizado para Xiaomi y navegadores modernos).

*   **URL:** `http://localhost:3000`
*   **Token:** Generado automáticamente al iniciar en Termux.
*   **Funciones:** Gestión de Staff, Configuración de Dueños, Broadcast Global, Terminal Segura y Monitor de RAM.
