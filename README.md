# 🌹 Acerca del proyecto

**TheYui-MD** es un Bot de WhatsApp Multi-Device desarrollado con **Node.js** y **Baileys**.

Cuenta con:

- 🤖 IA
- 🎵 Descargas
- 🎮 Juegos
- 👥 Administración
- 💰 Economía
- 🎨 Stickers
- 📥 Multimedia
- 🔍 Buscadores
- 👑 Owner
- ⚡ Optimizado
